Get IDS/IPS traffic filter rules (Snort) for a vulnerability

## Invocation

```
/vulnetix:vdb-traffic-filters [arguments]
```

Runs:

```bash
vulnetix vdb traffic-filters $ARGUMENTS -o json
```

The command is a deterministic CLI wrapper (`disable-model-invocation: true`). Output is JSON; the model summarizes it for the user.
