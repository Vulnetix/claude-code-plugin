Display current Vulnetix authentication status

## Invocation

```
/vulnetix:auth-status [arguments]
```

Runs:

```bash
vulnetix auth status $ARGUMENTS -o json
```

The command is a deterministic CLI wrapper (`disable-model-invocation: true`). Output is JSON; the model summarizes it for the user.
