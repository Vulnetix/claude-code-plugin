Authenticate with Vulnetix (interactive)

## Invocation

```
/vulnetix:auth-login [arguments]
```

Runs:

```bash
vulnetix auth login $ARGUMENTS
```

The command is a deterministic CLI wrapper (`disable-model-invocation: true`). Output is JSON; the model summarizes it for the user.
