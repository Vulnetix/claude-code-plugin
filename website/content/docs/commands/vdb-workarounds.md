Get workaround information for a vulnerability (V2)

## Invocation

```
/vulnetix:vdb-workarounds [arguments]
```

Runs:

```bash
vulnetix vdb workarounds $ARGUMENTS -V v2 -o json
```

The command is a deterministic CLI wrapper (`disable-model-invocation: true`). Output is JSON; the model summarizes it for the user.
