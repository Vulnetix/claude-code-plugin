Access the Vulnetix KEV (Known Exploited Vulnerabilities) catalogue

## Invocation

```
/vulnetix:vdb-kev [arguments]
```

Runs:

```bash
vulnetix vdb kev $ARGUMENTS -o json
```

The command is a deterministic CLI wrapper (`disable-model-invocation: true`). Output is JSON; the model summarizes it for the user.
