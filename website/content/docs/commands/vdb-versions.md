Get all known versions of a package across ecosystems

## Invocation

```
/vulnetix:vdb-versions [arguments]
```

Runs:

```bash
vulnetix vdb versions $ARGUMENTS -o json
```

The command is a deterministic CLI wrapper (`disable-model-invocation: true`). Output is JSON; the model summarizes it for the user.
