Ecosystem-scoped package and group lookups

## Invocation

```
/vulnetix:vdb-ecosystem [arguments]
```

Runs:

```bash
vulnetix vdb ecosystem $ARGUMENTS -o json
```

The command is a deterministic CLI wrapper (`disable-model-invocation: true`). Output is JSON; the model summarizes it for the user.
