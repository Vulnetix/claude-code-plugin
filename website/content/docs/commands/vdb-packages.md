Search for packages and assess security risk

## Invocation

```
/vulnetix:vdb-packages [arguments]
```

Runs:

```bash
vulnetix vdb packages search $ARGUMENTS -o json
```

The command is a deterministic CLI wrapper (`disable-model-invocation: true`). Output is JSON; the model summarizes it for the user.
