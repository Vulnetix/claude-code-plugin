Get advisory data for a vulnerability (V2)

## Invocation

```
/vulnetix:vdb-advisories [arguments]
```

Runs:

```bash
vulnetix vdb advisories $ARGUMENTS -V v2 -o json
```

The command is a deterministic CLI wrapper (`disable-model-invocation: true`). Output is JSON; the model summarizes it for the user.
